# Мультипространиство

## Введение

Плагин **мультипространиство** позволяет создавать несколько независимых пространств данных за счёт логической изоляции внутри одного экземпляра приложения.

#### Сценарии использования
- **Несколько магазинов или производственных площадок**: бизнес‑процессы и системные настройки в целом единообразны (единая система управления запасами, планирования производства, продаж и отчётности), но при этом важно, чтобы данные каждой бизнес‑единицы были изолированы и не пересекались.
- **Управление несколькими организациями или дочерними компаниями**: несколько организаций или дочерних структур в составе одной группы используют общую платформу, но у каждого бренда есть собственные данные о клиентах, товарах и заказах.

## Установка

В менеджере плагинов найдите плагин **мультипространиство** и включите его.

![](https://static-docs.nocobase.com/multi-space/Plugin-manager-NocoBase-10-15-2025_09_57_AM.png)

## Руководство пользователя

### Управление пространствами данных

После включения плагина перейдите на страницу настроек **«Пользователи и права»** и откройте вкладку **«Пространства»** для управления пространствами.

> Изначально существует встроенное пространство **«Неназначенное пространство»**, которое в основном используется для просмотра старых данных, не привязанных ни к одному пространству.

![](https://static-docs.nocobase.com/multi-space/Users-Permissions-NocoBase-10-15-2025_09_58_AM.png)

#### Создание пространства

Нажмите кнопку «Добавить пространство», чтобы создать новое пространство:

![](https://static-docs.nocobase.com/multi-space/Users-Permissions-NocoBase-10-15-2025_09_58_AM%20(1).png)

#### Назначение пользователей

После выбора созданного пространства вы можете указать пользователей, относящихся к этому пространству, в правой части экрана:

> **Подсказка.** После назначения пользователей пространству необходимо **вручную обновить страницу**, чтобы список переключения пространств в правом верхнем углу отобразил актуальные данные.

![](https://static-docs.nocobase.com/multi-space/Users-Permissions-NocoBase-10-15-2025_09_59_AM.png)

### Переключение и просмотр пространств

Вы можете переключать текущее пространство в правом верхнем углу экрана.
При нажатии на **значок глаза** справа (в активном состоянии) можно одновременно просматривать данные сразу из нескольких пространств.

![](https://static-docs.nocobase.com/multi-space/Goods-NocoBase-10-15-2025_10_26_AM.png)

### Управление данными в нескольких пространствах

После включения плагина система автоматически добавляет поле **«Пространство»** при создании коллекции.
**Только коллекции, содержащие это поле, участвуют в логике управления пространствами.**

![](https://static-docs.nocobase.com/multi-space/data-source-manager-main-NocoBase-10-15-2025_10_01_AM.png)

Для уже существующих коллекций вы можете вручную добавить поле «Пространство», чтобы подключить их к механизму управления пространствами:

![](https://static-docs.nocobase.com/multi-space/data-source-manager-main-NocoBase-10-15-2025_10_03_AM.png)

#### Логика по умолчанию

В коллекциях, которые содержат поле «Пространство», система автоматически применяет следующую логику:

1. При создании записей они автоматически связываются с текущим выбранным пространством;
2. При фильтрации данные автоматически ограничиваются выбранным в данный момент пространством.

### Классификация старых данных по пространствам

Для данных, которые существовали до включения плагина «мультипространиство», вы можете выполнить разнесение по пространствам в несколько шагов:

#### 1. Добавить поле «Пространство»

Вручную добавьте поле «Пространство» в старую коллекцию:

![](https://static-docs.nocobase.com/multi-space/data-source-manager-main-NocoBase-10-15-2025_10_18_AM.png)

#### 2. Назначить пользователей пространству «Неназначенное пространство»

Свяжите пользователя, который занимается обслуживанием старых данных, со всеми пространствами, включая **«Неназначенное пространство»**, чтобы он мог видеть записи, ещё не привязанные ни к одному пространству:

![](https://static-docs.nocobase.com/multi-space/Users-Permissions-NocoBase-10-15-2025_10_14_AM.png)

#### 3. Переключиться на просмотр данных из всех пространств

В верхней части экрана выберите просмотр данных по всем пространствам:

![](https://static-docs.nocobase.com/multi-space/Goods-NocoBase-10-15-2025_10_20_AM.png)

#### 4. Настроить страницу для распределения старых данных

Создайте новую страницу, предназначенную для распределения старых данных. Отобразите поле «Пространство» на **странице списка** и **странице редактирования**, чтобы можно было вручную менять принадлежность записей к пространствам.

![](https://static-docs.nocobase.com/multi-space/Goods-10-15-2025_10_21_AM.png)

Сделайте поле «Пространство» редактируемым

![](https://static-docs.nocobase.com/multi-space/Goods-10-15-2025_10_22_AM.png)

#### 5. Ручное распределение данных по пространствам

С помощью настроенной на предыдущем шаге страницы вручную редактируйте записи и постепенно назначайте им корректные пространства (при необходимости вы можете также настроить массовое редактирование).
