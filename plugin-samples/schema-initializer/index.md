# Инициализатор схемы

[Инициализатор схемы](/plugin-development/client) используется для добавления в интерфейс различных блоков, полей, действий и многого другого.

В зависимости от ваших потребностей могут быть следующие сценарии расширения:

- Добавить элементы в существующий инициализатор.
- Создать новый инициализатор

На основе описанных выше сценариев мы приводим следующие примеры:

**Добавление элементов в существующий инициализатор**

- [Добавление простого блока](/plugin-samples/schema-initializer/block-simple)
- [Добавление блока данных](/plugin-samples/schema-initializer/block-data)
- [Добавление блока данных с помощью модального окна](/plugin-samples/schema-initializer/block-data-modal)
- [Добавление простое действие](/plugin-samples/schema-initializer/action-simple)
- [Добавление действия с помощью модального окна](/plugin-samples/schema-initializer/action-modal)

**Создание нового инициализатора**

- [Встроенный инициализатор в блоке — настройка полей](/plugin-samples/schema-initializer/configure-fields)
- [Встроенный инициализатор в блоке — настройка действий](/plugin-samples/schema-initializer/configure-actions)
