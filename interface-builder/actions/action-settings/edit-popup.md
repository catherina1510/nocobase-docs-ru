# Редактирование всплывающего окна

## Введение

Любое действие/поле, которое может открыть всплывающее окно при нажатии, поддерживает настройку способа открытия всплывающего окна, размера и т. п.

- Диалоговое окно

![20251027212905](https://static-docs.nocobase.com/20251027212905.png)

- Большой
- Средний (по умолчанию)
