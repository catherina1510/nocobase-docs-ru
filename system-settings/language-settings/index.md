# Настройки языка

В разделе «Настройки системы» в параметре «Включённые языки» можно настроить глобальную языковую среду системы. Первый язык в списке используется как язык по умолчанию.

![20240324192005](https://static-docs.nocobase.com/20240324192005.png)

Если включено несколько языков, пользователи могут задать предпочитаемый язык в меню «Личные настройки» в правом верхнем углу страницы.

![20240324192509](https://static-docs.nocobase.com/20240324192509.png)

Если используемый язык переведён не полностью, можно использовать плагин [Управление локализацией](/system-settings/localization-management/) для добавления или редактирования переводов.

![20240324193055](https://static-docs.nocobase.com/20240324193055.png)
