# Управление локализацией

## Введение

Плагин управления локализацией предназначен для управления и реализации процесса локализации NocoBase. Он переводит меню, коллекции, поля и все плагины NocoBase для адаптации к языку и культуре конкретного региона.

## Установка

Это встроенный плагин, дополнительная установка не требуется.

### Синхронизация записей перевода

<img src="https://static-docs.nocobase.com/202404202134850.png"/>

Сейчас можно синхронизировать следующее:

- локальные языковые пакеты системы и плагинов
- заголовки коллекций, заголовки полей и метки опций полей
- заголовки меню

После синхронизации система покажет все переводимые записи для текущего языка.

<img src="https://static-docs.nocobase.com/202404202136567.png"/>

:::info{title=Примечание}
В разных модулях могут быть одинаковые исходные текстовые записи, их нужно переводить отдельно.
:::
